# TODO BINGO

갤럭시용 오프라인 할 일 빙고 앱입니다. Android 8.0 이상을 지원합니다.

## GitHub에서 APK 받기

1. ZIP 압축을 풀고, **숨김 폴더인 `.github`를 포함해** 압축을 푼 파일들을 저장소 최상위에 올립니다. 저장소 첫 화면에 `app`, `gradlew`, `settings.gradle.kts`가 보여야 합니다.
2. `main`에 올리면 Actions의 **Build Android APK**가 자동 실행됩니다. **Run workflow**로 수동 실행할 수도 있습니다.
3. 성공한 실행의 **Artifacts → TODO-BINGO-APK**를 다운로드하고 압축을 풉니다. 갤럭시에서 APK를 열고, 기기가 요청하면 파일을 연 앱에 설치 권한을 허용합니다.
4. 홈 화면을 길게 눌러 **위젯 → TODO BINGO**를 추가합니다. 앱의 **설정**에서 알림과 정확한 알람 권한을 허용합니다.

## 업데이트해도 데이터를 유지하려면

계속 사용할 앱은 첫 설치 전에 고정 서명 키를 갖추세요. Secrets 없이 빌드하면 해당 실행에만 쓰는 디버그 키로 서명한 `TODO-BINGO-test.apk`가 나옵니다. 테스트판을 사용했다면 JSON 백업 후 삭제·재설치하고 복원하세요.

터미널에서 한 번만 키를 만듭니다. 키와 암호는 개인적으로 보관하세요.

```bash
keytool -genkeypair -storetype PKCS12 -keystore todobingo.p12 -alias todobingo -keyalg RSA -keysize 3072 -validity 10000 -dname "CN=TODO BINGO"
base64 < todobingo.p12 | tr -d '\n'
```

저장소 **Settings → Secrets and variables → Actions**에 둘 다 추가합니다.

- `BINGO_SIGNING_BASE64`에는 위 두 번째 명령의 전체 출력을 넣습니다.
- `BINGO_KEY_PASSWORD`에는 첫 번째 명령에서 지정한 암호를 넣습니다.

Actions를 실행하면 `TODO-BINGO.apk`를 받을 수 있습니다. 다음 버전도 같은 키와 앱 ID로 빌드하고 `app/build.gradle.kts`의 `versionCode`를 올리면 기존 앱 위에 설치할 수 있습니다.

## 앱 동작

달성률은 입력한 할 일 중 완료한 비율입니다. 올빙고는 빈 칸 없이 전체 칸을 완료하면 표시됩니다. 판 크기를 줄일 때 빠져나온 칸은 빈 칸으로 이동합니다. 공간이 부족하면 할 일을 줄인 뒤 판 크기를 변경할 수 있습니다. 프리셋을 불러오거나 전날을 복사할 때는 확인창을 거쳐 현재 판을 교체합니다.

알림은 기본값이 꺼져 있습니다. 알림음에서 무음을 선택하고 진동을 켜면 진동만 울리고, 둘 다 끄면 알림만 표시됩니다. 정확한 알람 권한이 없으면 안드로이드가 갱신이나 알림을 늦게 전달할 수 있습니다. 앱을 열거나 위젯을 누르면 기기 날짜를 다시 확인합니다.

## 확인 절차

- 3×3, 4×4, 5×5에서 추가·수정·삭제·장기 누르기 이동과 가로·세로·대각선 판정을 확인합니다.
- 갤럭시 홈 화면에서 위젯을 추가하고 크기를 바꿉니다. 위젯으로 체크한 결과를 앱에서 확인합니다.
- 화면을 잠근 상태에서 시작·마무리 알림을 확인합니다. 재부팅 전후에 알림과 자정 전환을 확인합니다.
- 자정 뒤 반복 항목 위치와 미완료 가져오기를 확인합니다. 프리셋 관리, 과거 삭제, JSON 백업·복원을 실행합니다.
- 비행기 모드에서 앱과 위젯을 사용합니다. 같은 키로 새 APK를 덮어 설치하고 데이터가 남아 있는지 확인합니다.
